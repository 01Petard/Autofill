# 智填 Chrome / Edge 商店资料

## 简短说明

使用你自己的 AI 模型理解网页字段并生成安全测试数据，按站点授权后确定性填写表单，不自动提交。

## 详细说明

智填是一款面向测试、开发和重复数据录入场景的 AI 表单助手。用户为当前站点授权后，可以通过页面悬浮球扫描可填写字段；扩展将字段标签、类型和选项发送到用户配置的 OpenAI 或 Anthropic 兼容模型，再把模型返回的结构化结果写入输入框、文本域、下拉框、复选框、单选框和可编辑区域。

当前版本不会导入业务数据，不会读取字段已有值，也不会自动提交表单。提交、删除、支付、审批和发布操作始终由用户决定。

## 权限用途

- `storage`：在本地保存模型配置、启用站点和悬浮球位置
- `activeTab`：识别用户当前主动操作的标签页
- `scripting`：仅在用户授权的站点注入悬浮球和确定性填充逻辑
- 可选站点权限：访问用户主动启用的网页源站，以及用户自行配置的模型接口源站

## 发布前素材

建议商店截图包含：模型设置页、当前站点授权弹窗、悬浮球分析状态、填充完成但未提交的表单。隐私政策文件需要部署到公开 HTTPS 地址后填写到商店后台。
