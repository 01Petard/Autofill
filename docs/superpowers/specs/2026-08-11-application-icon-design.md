# 应用图标替换设计

## 目标

将用户提供的 1254 × 1254 高分辨率 PNG 设为智填扩展的统一应用图标，覆盖浏览器扩展入口、扩展页面和网页悬浮启动器，并确保后续构建不会恢复旧图标

## 资源设计

- 将原始 PNG 保存为项目内唯一源图
- `scripts/generate-icons.mjs` 从源图生成 16、32、48、128 像素的 Manifest 图标
- 页面展示和悬浮启动器复用同一源图或其生成产物，不维护重复设计文件
- 保持图片宽高比，不裁切、不增加滤镜

## 展示范围

1. Manifest 的扩展图标和工具栏动作图标
2. 弹窗头部，替换现有“填/A”文字圆标
3. 设置页标题区，在标题文本左侧展示图标
4. 网页悬浮启动器，替换现有“填”文字
5. 弹窗和设置页的浏览器标签 favicon

## 交互与兼容性

- 不改变弹窗、设置页现有业务结构和文字
- 不改变悬浮启动器的点击、拖动、禁用和状态提示行为
- 加载状态继续使用省略号，完成后恢复图标
- 图标提供替代文本或沿用按钮现有无障碍标签
- 不新增网络请求，不扩大扩展权限

## 验证

- 校验四个 Manifest 图标均存在且尺寸正确
- 校验弹窗、设置页和悬浮启动器均引用统一图标
- 运行现有测试、类型检查、代码检查和完整构建
- 运行发布包校验，确认图标进入最终产物
